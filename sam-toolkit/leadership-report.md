# Leadership report

A one-page report for the executive sponsor or governance council. It ties each control to a number, the number to the decision it drove, and that decision to a result in money or risk, so leaders see why the practice earns its funding.

Complete one copy per reporting period. Clause references are to the shared crosswalk (`XW-` rows).

## The chain

For each control you report on, fill one row: the control, the number that shows how it's working, the decision the number led to, and the outcome. If a number led to no decision, say so; a number nobody acts on is a candidate to drop. [[XW-025]]

Keep the set short. Use five or fewer KPIs, each with a definition, an owner, a data source, and a review date. Give each KPI a target and an action to take when it's missed.

## Savings and risk

Report two things side by side: money saved or avoided, and risk reduced. Count only savings you can back with evidence. Put adverse trends, such as rising invoice errors or spend outside procurement, next to the savings, not in a footnote. [[XW-012]]
