About

My background is business analysis, development and governance. The kit is my own project, and it doesn't speak for an employer.

The kit

It's nine governance methods for keeping a software estate in order. They cover application inventory and rationalization, access reviews, AI intake, hardware and software lifecycle, audit response, program setup and maturity. Each one maps to ISO/IEC 19770, COBIT 2019, ISO/IEC 27001 and ISO/IEC 42001, and each runs the same way in Claude, Codex or Microsoft Copilot.

I built it to do this work the same way each time. It isn't affiliated with IAITAM or any standards body.
