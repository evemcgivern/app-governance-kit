Seven governance tools, plus a router and a study coach

Each tool ships as a Claude skill, a Codex skill, and a Copilot agent, plus a checklist, SOP, template, and platform guide you can run by hand. Every one is exercised against Halden Logistics, a fictional demo estate with planted problems, so you can see exactly what it finds. Looking for working files instead? Get the free SAM toolkit templates.

Install

Download all seven governance tools, the router, and the study coach for your platform, or one tool from its card below. Each ZIP holds one folder per tool. Prefer git? The README has the clone-and-copy steps.

Claude Code, terminal
  1. Install it: curl -fsSL https://claude.ai/install.sh | bash on macOS, Linux, or WSL; irm https://claude.ai/install.ps1 | iex in Windows PowerShell; or brew install --cask claude-code. Run claude once to sign in (needs a Pro, Max, Team, Enterprise, or Console account). Claude Code setup docs.
  2. Add the marketplace: claude plugin marketplace add evemcgivern/agent-skills.
  3. Install the plugin: claude plugin install app-governance-kit@evemcgivern-skills. Inside a session, the same steps are /plugin marketplace add evemcgivern/agent-skills and /plugin install app-governance-kit@evemcgivern-skills.
  4. Type /app-governance-kit:access-review, or ask for a tool by name.
More
  • What you get: the seven tools, the router, the study coach, and the app governance agent. Plugin skills appear as /app-governance-kit:<skill>.
  • Without the plugin: unzip claude-skills.zip -d ~/.claude/skills. For one project only, use that project's .claude/skills folder. Skills then appear as /access-review. For the agent, save the app governance agent to ~/.claude/agents; it loads the router skill, so install the skills first.
  • Update: claude plugin update app-governance-kit@evemcgivern-skills. Auto-update is off by default for marketplaces other than Anthropic's, so run it after each release. For unzipped skills, unzip the new ZIP over them.
  • Check it worked: claude plugin list shows app-governance-kit@evemcgivern-skills, and typing / lists its skills.
  • Safe trial: ask for an access review of accounts.csv, employees.csv, and apps.csv from the demo estate. It should flag ACC-019, ACC-063, and ACC-104 as orphaned.
  • Plugin docs.
Claude Code, desktop app
  1. Install the Claude desktop app for macOS, Windows, or Linux, sign in, and open the Code tab.
  2. Start a Local session (not Cloud).
  3. Click + next to the prompt box, then Plugins, then Add plugin. The browser lists plugins from marketplaces you have added, so add evemcgivern/agent-skills first from the terminal (claude plugin marketplace add evemcgivern/agent-skills).
  4. Select app-governance-kit and choose your user account as the scope.
More
  • What you get: the same plugin as the terminal. The terminal, the desktop app's local sessions, and the VS Code extension read the same settings, so a user-scope install in one shows up in the others. Local sessions also load skills in ~/.claude/skills.
  • Cloud sessions: they don't load plugins installed on your computer.
  • Update: claude plugin update app-governance-kit@evemcgivern-skills in a terminal. +, then Plugins, then Manage plugins enables, disables, or uninstalls it.
  • Check it worked: type / in a local session and look for /app-governance-kit:access-review.
  • Safe trial: run the access review on the three demo estate files listed under the terminal steps.
Claude app (claude.ai, Desktop chat, Cowork)
  1. Turn on Code execution and file creation in Settings, then Capabilities. On Enterprise, an owner first turns on code execution and skills in Organization settings, then Plugins & skills.
  2. Download one tool's Claude ZIP from its card below. The app takes one skill per ZIP.
  3. Go to Customize, then Skills. Click +, then Create skill, then Upload a skill, and choose the ZIP.
  4. In a chat, ask for the tool by name: "Use the access review skill on these files."
More
  • What you get: one tool per upload. Repeat for each tool you want.
  • Cowork: the Desktop app's Cowork tab loads the skills turned on for your claude.ai account, so an upload here covers it.
  • Update: delete the skill (open it, turn it off, then ..., Delete) and upload the new ZIP.
  • Check it worked: the skill shows in Customize, then Skills, with its toggle on.
  • Safe trial: attach accounts.csv, employees.csv, and apps.csv from the demo estate and ask for an access review. It should flag ACC-019, ACC-063, and ACC-104 as orphaned.
  • Help article.
Codex (CLI, IDE extension, desktop app)
  1. Install it: curl -fsSL https://chatgpt.com/codex/install.sh | sh, then run codex and sign in with ChatGPT. Codex CLI docs. For VS Code, Cursor, or Windsurf, install the Codex extension.
  2. Add the skills: unzip codex-skills.zip -d ~/.agents/skills. For one repo only, use that repo's .agents/skills folder.
  3. Type $access-review, or describe the task and let Codex pick the skill.
More
  • What you get: the seven tools, the router, and the study coach.
  • Where they work: standalone skills work in the Codex CLI, the IDE extension, and the ChatGPT desktop app, where Codex runs. In the desktop app, open Skills in the sidebar to see them. Skills docs.
  • Update: unzip the new ZIP over the old folders. Codex picks up changes; if one doesn't appear, restart Codex.
  • Check it worked: run /skills in the CLI or IDE extension and look for access-review.
  • Safe trial: ask for an access review of the three demo estate files. It should flag ACC-019, ACC-063, and ACC-104 as orphaned.
ChatGPT

Skills upload only on ChatGPT Business, Enterprise, Healthcare, and Edu, when the workspace allows it. On Free, Go, Plus, and Pro, use a project (steps under More).

  1. In the sidebar, select Plugins, then the Skills tab in the Plugin Directory.
  2. Select Create, then Upload from your computer, and choose one tool's Codex ZIP from its card below.
  3. Wait for ChatGPT's scan. A skill marked Needs Review asks you to check it first.
  4. In a chat, type @ to pick the skill, or ask for the tool by name.
More
  • What you get: one tool per upload. ChatGPT and Codex use the same skill format, but OpenAI doesn't list which upload file types it accepts, and this kit hasn't been tested there. If the upload is refused, use a project.
  • Admins: Enterprise and Edu admins control Enable skills and Enable skill uploading in Permissions & roles.
  • Project instead (any plan): select New project in the sidebar. In ..., then Project settings, paste the tool's agent-instructions.md from copilot-agents.zip. Add the files from its knowledge folder, plus your data. Free plans allow 5 project files, so add the data and checklist.md first.
  • Not supported: skill folders on your computer work only in the ChatGPT desktop app's Codex, not in ChatGPT chat on the web. Personal plans can't create new custom GPTs.
  • Update: upload the new ZIP, or replace the project's instructions and files.
  • Check it worked: the skill shows on the Skills page, and @ lists it in a chat.
  • Safe trial: attach accounts.csv, employees.csv, and apps.csv from the demo estate. It should flag ACC-019, ACC-063, and ACC-104 as orphaned.
  • Sources: Skills in ChatGPT, Projects, GPTs.
Microsoft 365 Copilot and Copilot Studio

Create an agent in Agent Builder or Copilot Studio. Unzip copilot-agents.zip; each tool is a folder.

  1. Paste agent-instructions.md into the agent's instructions. The limit is 8,000 characters; these are under 3,000.
  2. Upload the files in knowledge/ as knowledge sources. If an upload rejects .md files, rename them to .txt.
  3. Run test-script.md against the demo estate to check it works.
More
  • What you get: one agent per tool. Build one for each tool you need, including the router.
  • Copilot chat (no agent): paste a tool's chat-prompt.md into a chat, then attach your data files.
  • Skills (preview): organizations in Microsoft's Frontier Program can add a skill package on the agent's Configure tab, under Skills. Microsoft's example ZIP has SKILL.md at the top, while our ZIPs hold a folder, so zip the folder's contents. Not tested with this kit. Docs.
  • Update: replace the instructions and knowledge files with the new release's.
  • Check it worked: test-script.md lists the pass checks. For access review, it should flag ACC-019, ACC-063, and ACC-104 as orphaned.
  • Safe trial: the test scripts use the demo estate files.
Other assistants
  1. Open a tool's chat-prompt.md from copilot-agents.zip.
  2. Paste it into a new chat.
  3. Attach your data files, or the demo estate files for a trial.
More
  • Agent Skills support: if your assistant reads SKILL.md folders, use the Codex or Claude ZIP. Check its docs for the folder it reads.
  • Update: paste the prompt from the new release.
  • Check it worked: the access review on the demo estate should flag ACC-019, ACC-063, and ACC-104 as orphaned.
Troubleshooting
  • Plugin skill not found in Claude Code: check claude plugin list. If you installed from your shell during a session, run /reload-plugins. Plugin skills carry a prefix: /app-governance-kit:access-review.
  • Unzipped skill not found in Claude Code: each skill needs its own folder with SKILL.md, such as ~/.claude/skills/access-review/SKILL.md. If you created ~/.claude/skills during the session, run /reload-skills.
  • Skill not found in Codex: check the folder is ~/.agents/skills/access-review/SKILL.md, then restart Codex.
  • ZIP rejected by the Claude app: upload one tool's ZIP, not claude-skills.zip, and check code execution is on.
  • Old version still running: run claude plugin update app-governance-kit@evemcgivern-skills, then run /reload-plugins or start a new session. For uploaded skills, delete and upload again.
