Application governance, made traceable

Application governance: portfolio, AI, and access controls, traceable to ISO/IEC 19770, COBIT 2019, ISO/IEC 27001, and ISO/IEC 42001.

The App Governance Kit is a free, MIT-licensed set of eight governance methods by Eve McGivern. It is not a platform, certification, or legal advice.

Six stages, request to retirement

Three areas, one set of tools

Application portfolio management

Application portfolio management keeps the inventory accurate, assigns ownership, and runs rationalization reviews so a portfolio doesn't quietly outgrow what anyone can govern.

AI governance

Application governance can touch on new AI systems, score their risk, and keep them inventoried and reviewed alongside the rest of the software estate, not tracked separately or missed.

Access controls

Access controls run periodic reviews, catch orphaned and excessive access, and hold privileged accounts to a shorter, tighter review cycle.
