Practicum

Seven hands-on exercises, all built around Halden Logistics and the demo data this kit's tools use. Work each one by hand with only a checklist, then enter what you found below and check it — no installs, no AI shortcuts, no one grading over your shoulder.

Start with practicum/README.md on GitHub if you haven't worked these exercises before — it explains how self-checking works and the order to take them in. The answer key behind this page, demo-estate/answer-key.json, is public in this repo; check your own answer before you look at it, or you're only checking whether you can copy one.
